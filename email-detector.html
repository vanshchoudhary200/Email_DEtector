Getting Started

1

Install Dependencies

Clone the repository and install all required dependencies for frontend and backend.

npm install && npm run install:all
2

Configure Environment

Set up your MongoDB connection string and JWT secret in the backend .env file.

PORT=5000
MONGO_URI=mongodb://localhost:27017/suspicious_email_detector
JWT_SECRET=your_secret_here
3

Start MongoDB

Ensure MongoDB is running either locally or use the included Docker Compose setup.

docker compose up -d mongo
4

Seed Admin User

Create the first admin user to access the admin panel.

cd backend && npm run seed:admin
5

Run the Application

Start both frontend and backend servers with the development command.

npm run dev
6

Access the App

Open your browser and navigate to the frontend. Backend API runs separately.

Frontend: http://localhost:5173
Backend: http://localhost:5000/api/health
